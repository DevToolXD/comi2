Gboard에 넣기 (아이폰·갤럭시 공통)

  1. Gboard 설치 후 키보드로 설정
  2. 키보드 열고 왼쪽 위 톱니바퀴 → 테마
  3. 내 테마 → + → 위 이미지 선택
  4. 밝기 조절 후 완료 → 키 테두리 켜기 추천

갤럭시 카카오톡 배경PNG

알려드릴 점. 갤럭시 카카오톡 테마는 .apk로 만들어야 하고, 카카오 공식 샘플 프로젝트가 있어야 리소스 이름이 맞습니다. 작업 환경에서 카카오 서버 접속이 막혀 있어 정상 동작을 보장하는 테마 apk는 만들지 못했습니다. 대신 카카오톡 기본 배경 설정으로 바꾸면 아이폰 테마와 거의 같은 느낌이 납니다.

적용 방법

  • 모든 채팅방 — 카카오톡 → 설정 → 채팅 → 배경화면 → 앨범에서 선택
  • 특정 채팅방만 — 채팅방 → 메뉴(≡) → 채팅방 설정 → 배경화면

직접 다시 만들기

python3 -m pip install pillow
python3 tools/build_assets.py      # 테마 이미지 생성
python3 tools/package_ktheme.py    # .ktheme 패키징
python3 tools/build_keyboard.py    # 키보드 배경 생성

색은 ios/src/KakaoTalkTheme.css에서, 사진 순서는 tools/build_assets.py의 ORDER에서 바꾸면 됩니다.
